
CodeDomino: O Jogo de Dominó da Programação

O CodeDomino é um jogo educativo digital baseado na mecânica clássica do dominó, projetado para ajudar iniciantes a aprenderem e fixarem a sintaxe da linguagem Python. O tabuleiro divide-se em duas frentes de aprendizado: o lado esquerdo exibe blocos de programação visual ou lógica descritiva, enquanto o lado direito apresenta o código correspondente em Python. O objetivo é conectar a lógica conceitual à sua implementação real.

Como Funciona o Jogo

As peças de dominó são divididas ao meio e possuem duas informações distintas que precisam ser correlacionadas para formar a corrente no tabuleiro:
• Lado Esquerdo (Bloco de Programação): Representa a lógica de forma visual, pseudocódigo ou uma descrição em blocos (ex: "Se X for maior que 10").
• Lado Direito (Código Python): Representa a sintaxe exata da linguagem de programação Python (ex: if x > 10:).
Para fazer uma jogada válida, o jogador deve encaixar a ponta de uma peça da sua mão em uma das pontas livres do tabuleiro, correspondendo o Bloco de Programação com o seu respectivo Código Python, ou vice-versa.
